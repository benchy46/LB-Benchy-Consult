# LB-Benchy-Consult
Uses the principles of Ben Chay's experience in LB for consulting various design/company/department/timeline decisions

## Structure

- `knowledge-base/principles.md` — synthesized, evidence-backed patterns in Benjamin's engineering judgment, risk tolerance, communication style, leadership, supplier management, prioritization, and tooling/process habits.
- `knowledge-base/channels/*.md` — raw per-Slack-channel extracts (50 channels, ~2 years of history) that back every claim in `principles.md`.
- `knowledge-base/index.md` — how this was built, scope, known gaps (no DMs, no binary file content, a name-collision to watch for), and a per-channel signal rating.
- `.claude/skills/consult-as-benjamin/` — a Claude Skill that loads this knowledge base to answer "what would Benjamin do/say" questions in his actual style rather than a generic persona.
